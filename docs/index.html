A few terms, made simple

What is a JWT?

JWT stands for JSON Web Token. In the real Java app, it is a signed token that a server checks when you ask to open a protected page. This browser demo only displays a pretend placeholder.

What do numbers like 200, 201, 401 and 403 mean?

They are HTTP status codes: 200 = worked, 201 = account created, 401 = sign-in needed or credentials invalid, 403 = signed in but not allowed, 409 = account already exists.

Is this a real account I can use?

No. It is just a private practice session in your browser tab. It does not contact the Java server, create a real account, save your information, or generate a usable token.

Want to run the real Java API? Use the GitHub template and open Swagger locally. The online exercise stays separate from real user data.
